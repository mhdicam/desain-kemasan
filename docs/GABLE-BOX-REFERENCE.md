# Gable Box — geometric reference (preview only)

Source: `/dielines-v2/GBL_gable-box.svg`. Rectangular body spans 130 × 85 × 100 mm (cut/fold coordinates x18–448, y88–188). The GLB includes a front/back/side body, two pitched roof faces, triangular end caps, and two upright open-slot handles, built as 17 individual named renderable mesh pieces. Unlike the old STE fallback, the handle is **real absent geometry**, not a painted black hole or an image.

This is **not a certified physical assembly**. The handle detail, fold offsets, material thickness, closure, glue tabs, and the cutting-edge slot radius require CAD source validation and fabrication review. Only `front-wall` is authorized as a calibrated artwork surface (mapped to SVG `panelId:front`). Other surfaces are preview material. This avoids pretending the entire imported SVG silhouette maps cleanly to a 3D surface. UV atlas bounds are derived from the complete cut/fill (x15..468 y34..221) and default 3mm bleed: [12,31,471,224] mm. Different bleed requires reauthoring/variant mapping, not silent distortion.

**Acceptance before production:** render front/back/left/right/top/bottom screenshots; verify visible handle openings, roof/side continuity and zero closure overlap; print UV checker registration; verify constraints for thickness, allowance and cutting radii.
